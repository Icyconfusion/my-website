DD Racing Wheel

The DD racing wheel is a hardware project I made for Stasis YSWS. It is a controller I designed for sim racing. It uses a hoverboard motor to provide force feedback to the driver, creating a realistic rcing experience when used with racing sims. Additionally, the CAN bus to the steering wheel allows for buttons to be used for functions like upshifting, pit limiter and others. You can check out the project at the Github repo link below.
